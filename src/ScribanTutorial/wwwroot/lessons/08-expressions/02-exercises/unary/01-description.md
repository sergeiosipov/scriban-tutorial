Use the three unary operators in one expression.

Given `temp = 20` and `is_winter = true`, print:

- `signed_temp` — `temp` negated when `is_winter` is true, kept positive
  otherwise. Use the boolean inversion `!is_winter` to drive the choice,
  via a ternary.

So with `temp = 20, is_winter = true` the output should be `-20`.

The placeholders hide the negation operator, the not operator, and the
ternary sigils.
