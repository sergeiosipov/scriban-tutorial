A function call **is** an expression — its result can be combined with
other operators inline. Define a simple function `longest` that takes
any number of strings via `$` and returns the one with the largest
`.size`. Then print:

`pick: <longest>, length: <its size>`

Use the function in the same expression where you read its size.

With the data below the output should be `pick: javascript, length: 10`.
