The data model carries an `items` array of three colours and a
`replacement` colour. Data-model arrays are writable in place: assign
to an index and that element is swapped out — no fresh array needed.

Replace the **middle** element of `items` with `replacement`, then
print the whole array on one line. With the data below the output
should read:

    ["red", "yellow", "blue"]

Reminder: indices are zero-based, so the middle of a three-element
array sits at index 1, not 2.
